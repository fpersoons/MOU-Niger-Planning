Guide utilisateur — Planificateur Budgétaire Intrants Paludisme FY26-FY30

GHSC-PSM · MOU Niger Planning

Principe

L’application traduit les budgets disponibles dans le cadre du MOU en quantités d’intrants à commander pour le Niger (FY2027-FY2030), en trois onglets à remplir dans l’ordre. Tout est enregistré automatiquement dans le navigateur.

1. Budget

Un seul tableau, une ligne par année fiscale FY2026 à FY2030 : budget MOU, réserve d’assistance (AT, entreposage, distribution ; FY2026 : prévue, pour information), accruals (montants engagés, produits et assistance ; FY2026 : au 30/09/2026), report reçu et budget produits (= budget + report reçu − réserve − accruals).

Dernière colonne, report du solde : année suivante, lissé sur les années suivantes ou aucun report. Solde FY2026 (clos) = budget − accruals (tout l’engagé, assistance comprise) ; ensuite = budget produits non utilisé dans les scénarios.

2. Paramètres logistiques

  • Coûts par intrant ($ par unité d’achat) : prix EXW, coût livré bateau + route, coût livré avion. Valeurs par défaut : scénario de référence du 02/10/2026 (livré maritime du fichier Malaria MOU 27 Niger ; avion = EXW + fret aérien de référence). Bouton « Coûts par défaut » pour les rétablir. En mode avion, les quantités sont calculées avec le coût livré avion ; en mode bateau, avec le coût livré bateau + route.
  • Quantités USG — PSN 2027-2031 : quantités prévues d’être couvertes par le Gouvernement américain (USG) dans la quantification du Plan stratégique 2027-2031 (PSN), par intrant et par année ; le split contribution USG se calcule automatiquement. 2031 est hors MOU.
  • Les moustiquaires (MILDA), non prévues dans le MOU, sont masquées ; une case permet de les réafficher.

3. Scénarios

  • Automatique (split contribution USG) : tout le budget produits est réparti selon le split contribution USG de l’année.
  • Ajusté manuellement : on part des quantités maximales achetables, puis on les modifie ; le reste du budget se met à jour en direct.
  • Transport : avion ou bateau + route. Année à venir (FY2027) : avion par défaut, pour respecter le plan d’approvisionnement.
  • Par produit : split contribution USG, quantité commandable (quantité initialement prévue pour l’USG dans la quantification du PSN 2027-2031, ajustée au budget disponible), coût livré, quantité initialement prévue pour l’USG et écart (−4 % = 4 % de moins que prévu). Copier pour un e-mail, synthèse et export Excel aux couleurs de l’application (quantités, prix unitaires livrés et totaux par année, entièrement en formules liées à une feuille « Paramètres » modifiable).

L’application s’ouvre avec les valeurs par défaut ; vos modifications sont enregistrées automatiquement dans le navigateur. « Réinitialiser » revient aux valeurs par défaut. Pour conserver une hypothèse ou changer d’ordinateur : « Télécharger le scénario », puis « Charger un scénario » (il remplace les valeurs actuelles). Le scénario est propre au navigateur et à l’adresse : utilisez toujours www.chemlink.app/MOU-Niger-Planning/. Une nouvelle version de l’application ne modifie pas votre scénario ; « Réinitialiser » adopte les nouvelles valeurs par défaut.
