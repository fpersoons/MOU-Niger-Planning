Guide utilisateur — Planificateur Budgétaire Intrants Paludisme FY26-FY30

GHSC-PSM · MOU Niger Planning

Principe

L’application traduit les budgets disponibles dans le cadre du MOU en quantités d’intrants à commander pour le Niger (FY2027-FY2030), en trois onglets à remplir dans l’ordre. Tout est enregistré automatiquement dans le navigateur.

1. Budget

Un seul tableau, une ligne par année fiscale FY2026 à FY2030 : budget MOU, réserve d’assistance (AT, entreposage, distribution), accruals (montants engagés ; FY2026 : au 30/09/2026), report reçu et budget produits (= budget + report reçu − réserve − accruals).

Dernière colonne, report du solde : année suivante, lissé sur les années suivantes ou aucun report. Solde FY2026 (clos) = budget − accruals (la réserve non engagée en fait partie) ; ensuite = budget produits non utilisé dans les scénarios.

2. Paramètres logistiques

  • Coûts par intrant ($ par unité d’achat) : prix EXW, coût livré bateau + route, coût livré avion. Valeurs par défaut : fichier Malaria MOU 27 Niger (coût livré maritime) ; avion : estimation. Bouton « Coûts de référence MOU 27 » pour les rétablir.
  • PSN 2027-2031 : quantités financées par l’USG par intrant et par année ; le split se calcule automatiquement. 2031 est hors MOU.

3. Scénarios

  • Automatique (split PSN) : tout le budget produits est réparti selon le split PSN de l’année.
  • Ajusté manuellement : on part des quantités maximales achetables, puis on les modifie ; le reste du budget se met à jour en direct.
  • Transport : avion ou bateau + route. Année à venir (FY2027) : avion par défaut, pour respecter le plan d’approvisionnement.
  • Par produit : split, quantité à commander, coût livré, quantité PSN et couverture. Copier pour un e-mail, synthèse et export Excel.

Pour comparer deux hypothèses, dupliquez le scénario (barre sous l’en-tête). Pour changer d’ordinateur : JSON (export puis import).
